# SculptorAI — Security Architecture & Threat Defense

## 1. Safety Validator & AST Capability Sandbox

Executing AI-generated code on a user's machine presents severe risks if unrestricted. SculptorAI enforces a multi-layered defense strategy:

1. **Deterministic AST Code Analysis** (`lib/blender/validator.ts`):
   - Every script generated by any model is parsed into an Abstract Syntax Tree (AST) before it is shown to the user or queued for execution.
   - **Allowed Modules**: `bpy`, `math`, `mathutils`, `bmesh`, `random`.
   - **Strictly Blocked**:
     - System execution: `os.system`, `subprocess`, `posix`, `pty`.
     - Reflection bypasses: `__import__`, `importlib`, `getattr`, `setattr`, `globals()`, `locals()`.
     - Filesystem access: `open()`, `shutil`, `pathlib`, `tempfile`.
     - Network exfiltration: `socket`, `urllib`, `requests`, `http`.
     - Object traversal: `__subclasses__`, `__mro__`, `__bases__`.

2. **Human-in-the-Loop Approval**:
   - No script is executed silently. All scripts require explicit user approval via the Web Studio or Blender Add-on.

3. **Capability Score Matrix** (`components/security/SafetyScoreCard.tsx`):
   - Displays real-time risk rating (`LOW RISK` / `HIGH RISK`) with audit checkmarks visible directly inside the code viewer.

## 2. API Security & Prompt Injection Defense

- **Input Sanitization** (`lib/security/sanitize.ts`):
  - Strips adversarial prompt injection keywords (e.g., `"ignore all previous instructions"`, `"system override"`).
  - Sanitizes null bytes, control characters, and directory traversal tokens (`../`).
- **Distributed Rate Limiting** (`lib/security/rateLimiter.ts`):
  - Configurable rate limits on `/api/generate`, `/api/ai/edit`, and `/api/debug` preventing denial-of-service and quota drain.
- **Tenant Isolation & RLS**:
  - Supabase PostgreSQL Row Level Security guarantees users can only view and execute tasks on projects they own.
  - Secret keys (`GEMINI_API_KEY`, `SUPABASE_SERVICE_ROLE_KEY`) are kept exclusively on the server and are never sent to the browser client.
